# F020 Query after-sales information

The flow platform sends order delivery notice to the sale channel, with flow platform as the calling party And the sale channel can query the after sale message by some qualifications

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries review/refund details: inspect auditStatus, refundStatus and their comments. Request acceptance and refund completion are separate stages.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryMessageOfAfterSale`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:4775`; see [Protocol and environments](../protocol.md) for test-branch differences.
