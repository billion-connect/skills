# F007 Create a top-up order

The external sales channel calls the Flow platform to create a top-up order.

Operation: write; distribution documentation: listed.

## Backend behavior

Synchronously creates a top-up order with at most 5 suborders. Each suborder's iccid is an array; provide copies or days. ESIMCARD top-ups may be accepted before a scheduled query obtains the final result; tradeCode=1000 does not guarantee completion. Use F046 to verify the target order/card plan.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.createOrderHandle`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleOrderApiService.java:137`; see [Protocol and environments](../protocol.md) for test-branch differences.
