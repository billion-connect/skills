# F051 Get pickup points by product ID

The external sales channel calls the Flow platform to get pickup points by product ID.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

skuIds must be a nonempty array. Queries pickup points for the current channel and product set.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.querySelfPickPointBySku`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:5683`; see [Protocol and environments](../protocol.md) for test-branch differences.
