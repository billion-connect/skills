# F059 Query data booster products

The external sales channel calls the Flow platform to query data booster products.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries listed data booster products with optional skuId filtering. language uses zh/en, unlike most APIs' 1/2. dataPoolName identifies virtual pools with effective prices for the current channel.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryBoosterPackageGoodsHandle`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:6266`; see [Protocol and environments](../protocol.md) for test-branch differences.
