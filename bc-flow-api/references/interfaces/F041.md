# F041 Resend an eSIM email

The external sales channel calls the Flow platform to resend an eSIM email.

Operation: write; distribution documentation: listed.

## Backend behavior

Resends an order's eSIM email to the specified email address, producing a real external message. Execute only when the user explicitly requests sending/resending. Validates primary/distribution ownership and creates/processes a delivery task; API success does not prove inbox delivery.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.reSendESIMEmail`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleOrderApiService.java:1449`; see [Protocol and environments](../protocol.md) for test-branch differences.
