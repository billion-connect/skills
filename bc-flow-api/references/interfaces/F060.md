# F060 Query rechargeable eSIM product series

The external sales channel calls the Flow platform to query rechargeable eSIM product series.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries rechargeable eSIM product series and carrierFee. The distribution backend queries using the parent channel, but this endpoint is absent from the distribution documentation; the Skill does not execute it for distribution channels. Fees depend on the channel currency.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryResourceSeriesCarrierFee`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:6241`; see [Protocol and environments](../protocol.md) for test-branch differences.
