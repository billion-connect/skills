# F045 End an activated plan

The external sales channel calls the Flow platform to end an activated plan.

Operation: write; distribution documentation: listed.

## Backend behavior

Ends an activated plan at the resource provider. This write interrupts service and requires orderId, subOrderId and iccid. Distribution requests map to the related primary order before processing. Ending a plan is different from cancelling an order or refunding it.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.manuallyEndingPackage`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleOrderApiService.java:1549`; see [Protocol and environments](../protocol.md) for test-branch differences.
