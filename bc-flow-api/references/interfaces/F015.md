# F015 Query acceleration products

The external sales channel calls the Flow platform to query acceleration products.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

tradeData must be a nonempty array; each entry describes the order/card/acceleration type. The backend checks supplier applicability before querying available acceleration products.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryAccelerationPackageCommoditiesHandle`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:4286`; see [Protocol and environments](../protocol.md) for test-branch differences.

## Request parameters

These tables preserve the published field contract. Conditional requirements follow the field descriptions and backend notes above. The client performs partial structural validation; the server still validates product eligibility, permissions, inventory and balance.

| Field | Type | Required in docs | Description |
|---|---|---|---|
| `tradeType` | String | Y | F015- Query acceleration package commodities |
| `tradeTime` | String | Y | Communication time stamp |
| `tradeData` | Array | Y | Definitions are shown in the table below |

### tradeData

| Field | Type | Required in docs | Description |
|---|---|---|---|
| `orderId` | String | Y | Main order ID of flow platform |
| `iccid` | String | Y | Card number |
| `dayType` | String | Y | Plan type: 0-single-day acceleration; 1-plan upgrade; 2-total-volume upgrade |
| `language` | String | N | Language: 1-Chinese (default); 2-English |
