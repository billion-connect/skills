# F014 Query prepaid balance

The external sales channel calls the Flow platform to query prepaid balance.

Operation: read; distribution documentation: listed.

## Backend behavior

Returns isOpen and saleBalance. When isOpen=0, saleBalance is an empty string, not a zero balance. This is a read-only account query, not an account funding operation.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.querySaleAccountBanance`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:4264`; see [Protocol and environments](../protocol.md) for test-branch differences.
