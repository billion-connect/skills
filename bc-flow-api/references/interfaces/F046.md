# F046 Query plan usage by order and card

The external sales channel calls the Flow platform to query plan usage by order and card.

Operation: read; distribution documentation: listed.

## Backend behavior

Requires iccid and at least one of orderId/channelOrderId. Primary and distribution channels have separate ownership checks; non-self-operated channels are rate-limited. Missing records may return null, which is neither necessarily a business failure nor proof of zero usage.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryPackagesUsageInfo`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:5295`; see [Protocol and environments](../protocol.md) for test-branch differences.
