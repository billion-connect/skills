# F056 Query all acceleration products

The external sales channel calls the Flow platform to query all acceleration products.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries available acceleration products/prices by channel settlement method, country, skuId and other filters. When unitBase is returned, use it for data-unit conversion rather than assuming 1024.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.queryAllAccelerationPackageCommodities`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleOrderApiService.java:1734`; see [Protocol and environments](../protocol.md) for test-branch differences.
