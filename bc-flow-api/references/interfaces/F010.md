# F010 Query card validity

The external sales channel calls the Flow platform to query card validity.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

iccid is an array of 1–100 entries. Returns card validity/status, not an individual plan's remaining data; use F012/F046 for plan information.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryCardValidVersion2Point0`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:2454`; see [Protocol and environments](../protocol.md) for test-branch differences.

| Field | Type | Required in docs | Description |
|---|---|---|---|

### tradeData

| Field | Type | Required in docs | Description |
|---|---|---|---|
| `iccid` | String | Y | Card ICCID |
| `type` | String | Y | Type: 0-single-use card; 1-multi-use card; 2-physical SIM; 3-MiFi for sale; 4-rental MiFi; 5-eSIM |
| `status` | String | Y | Status: 0-card issued; 1-in use; 2-exhausted; 3-expired; 4-renewed; 5-decommissioned |
