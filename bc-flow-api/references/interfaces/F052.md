# F052 Query eSIM top-up products

The external sales channel calls the Flow platform to query eSIM top-up products.

Operation: read; distribution documentation: listed.

## Backend behavior

Queries rechargeable products by iccid; the response skuId is itself an array. For distribution channels, IDs are converted to products listed under the current distribution channel. Do not order using a parent channel's product IDs.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryESIMRechargeGoods`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:5709`; see [Protocol and environments](../protocol.md) for test-branch differences.
