# F008 Cancel an order

The external sales channel calls the Flow platform to cancel an order.

Operation: write; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Cancels an existing order and may cancel supplier procurement and roll back account/inventory changes. This differs from an F017 after-sales refund. Distribution channels are explicitly unsupported. The reviewed test branch additionally requires API after-sales permission caseId=29 and may return 9999/No permission; the production deployment has not been verified to use the same version.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.cancelOrderHandle`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleOrderApiService.java:792`; see [Protocol and environments](../protocol.md) for test-branch differences.
