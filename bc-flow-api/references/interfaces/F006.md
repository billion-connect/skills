# F006 Create an order including SIM cards

The external sales channel calls the Flow platform to create an order including SIM cards.

Operation: write; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Synchronously creates an order including cards: validates products, debits the account, waits for the supplier when necessary, then commits the transaction. At most 5 suborders; provide express or selfPickup. Each suborder needs planSkuCopies or days. F006 explicitly does not support distribution channels. The server still checks amounts, inventory, shipping and resource capabilities.

When supplied, `planSkuCopies` and `days` must each be integers from 1 to 730. A card-only F003 quote may contain `copies=1, days=0`; do not pass that zero to F006. For a card-only purchase, omit `planSkuId` and `days`, and use `planSkuCopies=1` from the valid quote; this does not buy an extra data plan. Do not fill required fields with days=0. After correcting an explicit parameter rejection, first query the original channel order ID to confirm no order exists, then reuse the same business identifiers for the retest.

The backend also supports `express.feeMethod`, omitted from the page table: `1` recipient pays, `2` sender pays (default). Recipient-paid shipping requires SF Express code `SF` and must match the user's shipping choice. For channels with automatic shipping charges, sender-paid shipping must match the configured carrier/destination price; `expressFee=0` cannot replace missing configuration. If no matching shipping price is found, report the configuration mismatch. Do not change server prices or silently switch the payer. An explicitly authorized recipient-paid choice can be used in the request.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.createOrderHandle`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleOrderApiService.java:137`; see [Protocol and environments](../protocol.md) for test-branch differences.
