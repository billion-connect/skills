# F054 Query identity verification status

The external sales channel calls the Flow platform to query identity verification status.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries identity verification status by iccid; language=2 requests English descriptions. Read-only: does not initiate verification or upload identity documents.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.queryRealNameStatus`.
