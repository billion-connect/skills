# F042 Query eSIM profile status

The external sales channel calls the Flow platform to query eSIM profile status.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries eSIM profile history for one iccid, including status, recordTime and eid. Unsupported supplier channels return an error; no records may return a successful empty array. This is not a QR retrieval endpoint.

Call chain: `SaleController.dispatchRequest` → `SaleOrderApiService.queryESIMProfileStatus`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleOrderApiService.java:1492`; see [Protocol and environments](../protocol.md) for test-branch differences.
