# F013 Validate cards for top-up

The external sales channel calls the Flow platform to validate cards for top-up.

Operation: read; distribution documentation: listed.

## Backend behavior

iccid must be a nonempty array. Calls the resource provider to check top-up eligibility. Success only reports this validation; it does not create a top-up order. F007 must be invoked separately.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryValidateAddPackageIccids`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:3369`; see [Protocol and environments](../protocol.md) for test-branch differences.
