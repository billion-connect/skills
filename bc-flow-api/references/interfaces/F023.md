# F023 Query daily usage

The external sales channel calls the Flow platform to query daily usage.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries daily usage; the backend still requires iccid, beginDate and endDate. Supplying channelOrderId selects an order-based query path; do not assume the date range still controls its results. A nonexistent card or one outside the channel may return a successful empty list. Empty results do not prove zero usage.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.dailyFlowQuery`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:4898`; see [Protocol and environments](../protocol.md) for test-branch differences.
