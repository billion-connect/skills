# F011 Query order information

The external sales channel calls the Flow platform to query order information.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries by channelOrderId and returns platform orderId, suborders and shipping details. Card and top-up response shapes differ. External orderStatus is mapped; it is not the raw sale_order status and does not prove an eSIM QR code is available.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryOrderInfoVersion2Point0`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:2744`; see [Protocol and environments](../protocol.md) for test-branch differences.
