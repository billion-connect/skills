# F012 Query plan usage

The external sales channel calls the Flow platform to query plan usage.

Operation: read; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Queries plan usage for one iccid, with channelOrderId, planStatus and time filters; rate-limited per card. The backend parses planStatus as an integer array. Card ownership and supplier capabilities apply. Do not use primary-channel credentials to bypass distribution data boundaries.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.queryPackagesUsedMsg`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:3055`; see [Protocol and environments](../protocol.md) for test-branch differences.
