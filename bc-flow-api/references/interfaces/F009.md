# F009 Update shipping information

The external sales channel calls the Flow platform to update shipping information.

Operation: write; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Forces shipping logisticsType=1 and calls SaleOrderHandleService.modifyOrderHandle. Changing recipient, address or shipping information is a write operation.

When updating an existing recipient-paid shipment, explicitly retain `feeMethod=1` if that choice still applies; omitting it may restore sender-paid shipping and recalculate fees. Channels with automatic shipping charges require a matching carrier/destination price for sender-paid shipping; `expressFee=0` cannot substitute for it. Do not change who pays merely to make the API accept the request.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.modifyLogisticMsg`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:2431`; see [Protocol and environments](../protocol.md) for test-branch differences.
