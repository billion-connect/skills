# F018 Cancel an after-sales request

The sales channel can obtain the list of commodities it can sell, with external sales channel application system as the calling party , And the sale channel can cancel the after sale apply

Operation: write; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Cancels an after-sales request by afterSaleId; this is a write operation. The reviewed test branch requires API after-sales allowlisting. It does not cancel the main sales order.

First confirm with F020 that the request has not been reviewed. An approved request (auditStatus=2) cannot be cancelled even when refundStatus=0 and the money has not arrived; observed rejection: `1114 / This application cannot be cancelled`. A pending refund does not imply an editable request.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.cancelAfterSale`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:4666`; see [Protocol and environments](../protocol.md) for test-branch differences.
