# F016 Create an acceleration order

The external sales channel calls the Flow platform to create an acceleration order.

Operation: write; distribution documentation: not listed (this alone does not prove the backend cannot support it).

## Backend behavior

Creates an acceleration order linked to originalOrderId. subOrderList must contain exactly one object with channelSubOrderId, iccid and skuId. Acceleration products are distinct from F061 data boosters.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.createAccelerationOrderHandle`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:4339`; see [Protocol and environments](../protocol.md) for test-branch differences.
