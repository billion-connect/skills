# F001 List covered countries

The external sales channel calls the Flow platform to list covered countries.

Operation: read; distribution documentation: listed.

## Backend behavior

Queries covered countries using the effective policies for the channel identified by the credentials. An empty list/null does not imply authentication failure; no effective policy produces a business error.

Call chain: `SaleController.dispatchRequest` → `SaleApiService.querySaleCoverCountrys`.
Source: `flow@93d717b36c/manage-api/src/main/java/com/op/flow/manage/api/service/SaleApiService.java:2253`; see [Protocol and environments](../protocol.md) for test-branch differences.
